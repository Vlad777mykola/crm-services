# contracts

This folder stores the generated API contract shared between backend and frontend.

- `openapi.json` — generated from backend Zod schemas (via `zod-to-openapi`). See Step 6.
- Frontend generates its typed API client/types from this file using Orval. See Step 7.
- This folder is a **build artifact directory**: files here are generated by `yarn contract:generate` and must not be edited by hand.

# contracts

This folder stores the **hand-written OpenAPI contract**, shared between backend and frontend.

- `openapi.yaml` — root OpenAPI document (info, servers, common schemas, and `$ref`s into `openapi/<module>/`).
- `openapi/<module>/paths.yaml` — path definitions for a module.
- `openapi/<module>/schemas.yaml` — request/response schemas for a module.

These YAML files are **source files**, written and edited by hand. They do not depend on backend Zod schemas or any code generation.

Generated artifacts derived from this contract (do not hand-edit):

- `backend/src/autogenerated/openapi.ts` — TypeScript types generated from this YAML via `yarn workspace backend openapi:generate-types`.
- `frontend/src/shared/api/generated/**` — typed API client generated from this YAML via Orval (see Step 7).

Backend Zod schemas stay plain/classic `zod` and are typed against the generated TypeScript types (`z.ZodType<GeneratedType>`) rather than generating or being generated from OpenAPI - see the `.cursor/rules/zod-openapi-contract.mdc` project rule for the full convention.
